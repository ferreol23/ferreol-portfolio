# v1.0.0 · 2026-10-28

**Première version en ligne** : https://ferreol23.github.io/ferreol-portfolio/

Tes vraies réalisations, une page d'accueil plus vivante, WhatsApp partout, et la publication
automatique sur GitHub Pages.

## Ajouté

- **Tes 3 réalisations** dans le portfolio : le portfolio du monteur vidéo, La Laiterie Douce et
  Maison Atelier (versions template), avec de vraies captures de chaque site (5 sur ordinateur + 1 sur téléphone).
- **Fenêtre de détail** quand on clique sur un projet : grande capture avec flèches et miniatures,
  description longue, « What's inside », outils utilisés, une note honnête sur le contenu d'exemple,
  et les boutons « Visit the live site », « I want something similar », « Ask on WhatsApp ».
- **« Recent work »** juste sous le hero : tes 3 projets en petites fenêtres de navigateur, en éventail.
- **Transition vers « Selected work »** façon fuzeshop.fr : le bandeau se resserre en carte au défilement.
- **Page Contact** : le visiteur choisit le type de projet et le délai, et ces choix arrivent en haut
  du message. Un service ou un projet cliqué pré-remplit le formulaire.
- **WhatsApp** : liens « Send me a message » (bas de page, Contact) et « Ask on WhatsApp » (projets),
  avec un message déjà écrit. Ton numéro n'est jamais affiché en texte.
- **Grand « FERREOL. » en bas** : les lettres proches de la souris se soulèvent comme une vague
  (au doigt, la lettre touchée fait un petit saut).
- **Lien Fiverr** rempli : tous les boutons « Hire me » mènent à ton profil.

## Modifié

- **Mise en ligne sur GitHub Pages** : le site est fabriqué en fichiers statiques (`out/`) et
  publié à chaque `git push` sur `main` (GitHub Actions). Les avis sont chargés dans le navigateur.
- **Photo** : la photo générée par IA est retirée ; le hero affiche ton initiale « F. » en attendant
  une vraie photo.
- **FAQ « How long does it take? »** : réponse honnête, sans chiffre inventé.
- Les liens internes (« Work », « See all projects ») s'arrêtent juste sous l'en-tête.

## Corrigé

- Le badge rond du hero ne fait plus défiler la page de côté.
- Sur téléphone, l'adresse longue des projets n'élargit plus la page.

## À savoir

- GitHub Pages ne permet pas d'envoyer des en-têtes de sécurité : la règle principale
  (Content-Security-Policy) est maintenant dans une balise `<meta>` (`src/lib/security.ts`).
- Le dépôt GitHub s'appelle maintenant **ferreol-portfolio** et il est **public**.
