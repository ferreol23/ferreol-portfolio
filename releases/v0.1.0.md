# v0.1.0 · 2026-10-22

Base du projet + page d'accueil complète.

## Ajouté

- **Projet** : Next.js 16, TypeScript, Tailwind CSS, connexion Supabase et vérification des formulaires (zod).
- **Design** : thème sombre noir + orange, avec un bouton pour passer en thème clair (le choix est mémorisé).
- **En-tête** : nom, menu (Accueil, Projets, Avis, Contact), bouton « Hire me », menu mobile.
- **Page d'accueil**, dans l'ordre :
  1. Accueil (titre animé mot par mot, photo avec lumière orange, badge qui tourne, réseaux sociaux)
  2. Bandeau orange des services qui défile
  3. Services (4 cartes)
  4. À propos
  5. Ce que vous obtenez (4 engagements)
  6. Comment je travaille (4 étapes)
  7. Projets
  8. Questions fréquentes
  9. Bandeau Fiverr
- **Pied de page** : réseaux sociaux, email, liens, copyright.
- **Animations** : apparition au défilement, survol des cartes, barre de progression en haut. Elles sont désactivées automatiquement pour les personnes qui ont choisi « réduire les animations » sur leur appareil.

## Sécurité

- Les clés Supabase restent dans `.env.local`, qui n'est jamais envoyé sur GitHub.
