# Versions du site

Chaque mise à jour du site reçoit un numéro de version et un fichier dans ce dossier
qui explique ce qui a changé.

## Comment lire les numéros

`v0.1.0` → `v0.2.0` → … → `v1.0.0`

- Le **deuxième chiffre** augmente à chaque nouvelle étape (nouvelles pages, nouvelles fonctions).
- Le **dernier chiffre** augmente pour une petite correction.
- **v1.0.0** = la première version mise en ligne.

## Récupérer une ancienne version

Sur GitHub : page du dépôt → **Tags** (ou **Releases**) → choisir la version → **Download ZIP**.
